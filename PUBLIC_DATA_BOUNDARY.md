# Public Data Boundary

Status: Current repository safety rule

Public GitHub content may include source code, schemas, non-sensitive examples, evidence-gated documentation, and redacted templates.

Do not publish:

- Discord invitation URLs that lack authorized-human approval, a guild ID, purpose, expiration state, or provenance;
- credentials, tokens, secrets, or credential locations;
- private hostnames, IP addresses, usernames, or local filesystem paths;
- private contact, customer, payment, contract, or health data;
- unapproved archival material;
- unsupported ownership, registration, runtime, or authority claims.

Authorized public Discord invitation URLs are routing records, not credentials. Webhook URLs, bot tokens, and private connection strings remain prohibited.

The internal code identifier `creative_guild` may route authorized Discord inputs. It has no independent legal, public, organizational, trademark, publishing, or archival authority. Human authorization is required before eligible material moves toward 📚 DrMarchand’s ⚛︎ Library™.
